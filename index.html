A production-grade career planning system that takes your current skills and target career goal, then orchestrates multiple LLM calls through LangChain to generate a personalized 4-week learning roadmap.   • Async API calls for parallel skill recommendation generation

Ghost Eye — Autonomous OSINT Agent

002 / 03

👁️ Agentic AI for open-source intelligence gathering

An autonomous OSINT intelligence agent that investigates any public target — person, brand, company, domain, or email — and produces a professional intelligence dossier. Built with LangChain function calling and OpenAI, the agent autonomously decides which of 6 specialized tools to use based on the target type, streams its reasoning live to a cyber-terminal UI, and generates downloadable PDF reports.

  • Multi-tool orchestration: Tavily web search, HaveIBeenPwned breach check, Wayback Machine, sentiment analysis, Wikipedia, business intel
  • LangChain function-calling with autonomous tool selection — agent decides which 2–4 tools to invoke per target
  • Real-time reasoning stream to a black-and-neon-green cyber-terminal interface
  • Interactive knowledge graph visualization using pyvis with extracted entities
  • CONFIDENTIAL PDF dossier generation via ReportLab + MongoDB-backed investigation history
